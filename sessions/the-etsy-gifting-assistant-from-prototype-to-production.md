## メモ

Day 2 の Etsy セッション。詳細なセッション要約は、音声・書き起こし・公式資料などを確認して後ほど補完する。

参考として、Derrick Kondo 氏の `agent-tackle-box` リポジトリを記録しておく。`agent-tackle-box` は AI agents 開発向けの toolkit で、LangGraph / LangChain agents を terminal 上で debug する `agent-debugger` を含む。state、messages、tool calls、store snapshots、semantic breakpoints、Python-level debugging を 1 つの Textual UI で扱える。
