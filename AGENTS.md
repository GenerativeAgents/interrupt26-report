# Repository Instructions

## Required Workflow

- When you change any file in this repository, perform a Red Team review before finishing.
- The Red Team review must look for factual errors, broken links, missing sources, misleading summaries, formatting issues, accidental sensitive data, and unintended files.
- After the Red Team review is complete, commit and push the changes to the remote repository.
- If commit or push cannot be completed, clearly report the blocker and the exact repository state.
